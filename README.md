# IRCTC NextGen

A calmer, more visual rail booking prototype built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The UI uses seeded demonstration data for trains, berth availability, journey tracking, and wallet activity. Booking and wallet actions are frontend simulations and do not connect to IRCTC services.
